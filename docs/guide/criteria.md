# Criteria and scores reference

A **criterion** is any number HANI2 measures for a negotiation: a metric column, an answer to a
questionnaire, or a score. Scores combine criteria after mapping each one to $[0, 1]$, where 1 is
the best value. This page lists every criterion that the built-in metrics provide, with its
direction, its default normaliser and its cost. How criteria are scaled, and why the reference is
frozen, is explained in [Evaluation criteria and normalisation](evaluation.md#evaluation-criteria-and-normalisation).

Each criterion has:

| Field | Meaning |
| --- | --- |
| `source` | `hard` (measured from the log), `soft` (judged by a language model), `subjective` (a questionnaire scale computed by a metric), `questionnaire` (an item or scale of the project's or study's own forms) or `score` |
| `level` | `negotiation` (one value per game) or `participant` (a post-session answer, one per person) |
| `direction` | `higher`, `lower` or `none`. A score that uses a criterion without a direction must state one |
| `normaliser` | The default mapping to $[0, 1]$ (below) |
| `cost` | `live` (computed when the game ends), `judge` (needs the offline judge run) or `questionnaire` (needs the participant's answers) |
| `coverage` | The share of the games that have a value (in the admin API with `coverage=true`) |

The list for one project or study, with the items of its own questionnaires and their coverage, is
served by `GET /api/admin/criteria?project=…` or `?study=<project>/<study>` (add `&coverage=true`) and printed by
`hani2 scores criteria <project>[/<study>] [--coverage]`.

## Normalisers

| Normaliser | Rule | Default for |
| --- | --- | --- |
| `bounded` | $\frac{x - lo}{hi - lo}\ \text{clipped to } [0, 1]$ | Columns with known bounds: `[0, 1]`, `0 or 1`, `1–7`, `[−1, 1]`, utilities, every questionnaire item and scale with its own bounds. |
| `advantage` | $\min(1, \max(0, x))$ | The `*_advantage` columns: no better than no deal (or worse) is 0, the best outcome is 1. |
| `reciprocal` | $\frac{s}{s + x}$ | Unbounded values where lower is better (counts, seconds, tokens, distances, US dollars). |
| `saturating` | $\frac{x}{x + s}$ | Unbounded values where higher is better, and unbounded values without a direction. |
| `percentile` | $\frac{\#\{r < x\} + \tfrac12 \#\{r = x\}}{n}$ | Any criterion, on request: the share of the reference games with a lower value (ties count half). |
| `clip` | $\frac{x - lo}{hi - lo}\ \text{clipped to } [0, 1]$ | Any criterion, on request, with your own bounds. |

With direction `lower`, every rule is turned around ($1 - \cdot$). `reciprocal` and `saturating` are the same rule seen from the two directions; $s$ is the median of the project's frozen reference (the mean when the median is 0, and 1 when there is no reference yet).
